Invenza

Inventory Management System — Admin Dashboard Template

A modern, responsive inventory management admin dashboard built with HTML, Tailwind CSS, and vanilla JavaScript. Complete set of pages and components for managing products, sales, purchases, customers, suppliers, invoices, expenses, and reports.

Installation

Follow these simple steps to get started with Invenza:

  1. Download the Invenza template ZIP file from your marketplace account and extract it on your computer.
  2. Open the extracted invenza folder. You can open it with a code editor such as Visual Studio Code if you want to customize the template.
  3. Find and open index.html in your web browser. It will automatically redirect you to dashboard.html.
  4. No build process is required. Invenza is a ready-to-use HTML template and does not require Node.js, npm, or other build tools.
Note: You can preview the template directly in your browser. For features that use AJAX requests or API integrations, run the template through a local server such as Live Server in Visual Studio Code, XAMPP, or another standard static web server.
Tip: If you are new to HTML templates, make a backup copy of the original invenza folder before making any customizations.

Dark Mode

Invenza includes a built-in dark mode toggle. The theme preference is saved to localStorage and persists across sessions.

How it works

  • The .dark class is added to <html> when dark mode is active.
  • Tailwind's dark: variants are used throughout the template.
  • The toggle button is located in the sidebar footer.
  • Theme state is stored in localStorage.getItem('sf_theme').

To add dark mode to new elements

<div class="bg-white dark:bg-slate-800">
  <p class="text-gray-800 dark:text-gray-200">Content</p>
</div>

Tailwind CSS

Invenza uses Tailwind CSS compiled to a static CSS file via the Tailwind CLI. The source CSS is in src/input.css and is built to assets/css/tailwind.css. Configuration is in tailwind.config.js at the project root.

Build required: Run npm run build to compile Tailwind CSS. Use npm run watch during development for automatic recompilation.

Sidebar Toggle

The sidebar can be toggled via the hamburger button in the header. Handled in assets/js/app.js.

// Toggle sidebar
document.querySelector('.sidebar-toggle').addEventListener('click', () => {
  document.querySelector('.app-sidebar').classList.toggle('open');
  document.querySelector('.app-main').classList.toggle('sidebar-open');
});

Theme Toggle

Dark mode toggle logic in assets/js/app.js:

const themeToggle = document.querySelector('.theme-toggle');
const html = document.documentElement;

// Load saved theme
if (localStorage.getItem('sf_theme') === 'dark') {
  html.classList.add('dark');
}

themeToggle.addEventListener('click', () => {
  html.classList.toggle('dark');
  localStorage.setItem('sf_theme', html.classList.contains('dark') ? 'dark' : 'light');
});

Troubleshooting

If you experience any issues while setting up or using Invenza, check the solutions below. Most common issues can be resolved by checking the file structure or running the template through a local server.

Before troubleshooting: Make sure you have extracted the complete Invenza ZIP file and have not moved, renamed, or deleted any of the included folders or files.

The dashboard does not load correctly

Make sure the complete invenza folder has been extracted from the downloaded ZIP file. Keep the original folder structure unchanged and make sure index.html and dashboard.html are in their original locations.

The page looks unstyled or the design is broken

Check that the assets folder is present and has not been moved or renamed. The CSS and JavaScript files inside the assets folder are required for the template to display correctly.

AJAX or API features are not working

Some browser features may be restricted when HTML files are opened directly from your computer. For AJAX requests or API integrations, run Invenza through a local server such as Live Server in Visual Studio Code, XAMPP, or another standard static web server.

Images, icons, or other assets are missing

Make sure the assets folder and its contents have not been moved, renamed, or deleted. If you copied individual files instead of the complete project folder, download and extract the original package again.

My changes are not showing in the browser

Save your changes and refresh the browser. If the previous version is still displayed, perform a hard refresh or clear your browser cache.

The template works locally but not on my server

Make sure the complete project folder has been uploaded to your hosting server and that the folder structure is unchanged. Also check that your server preserves the correct file and folder names.

Still having an issue?

If the problem continues, first make sure you are using the original files from the downloaded package. When requesting support, provide a short description of the issue, the browser you are using, and any error message you see. This will make it easier to identify the problem.

Tip: Before making major customizations, keep a backup copy of the original Invenza files so you can restore them if needed.
